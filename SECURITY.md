# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting on the affected repository ("Report a vulnerability" under the Security tab), or email evan.j.ray@gmail.com with the repository name, the affected version or commit, and steps to reproduce.

You will get an acknowledgement within 72 hours and a fix or a mitigation plan within 14 days for a confirmed issue. Credential leaks are rotated first and then removed from the tree; history is rewritten only when a value cannot be rotated.

## Supported versions

Only the latest release of each repository receives fixes.
