# Raylytics

Small, well-kept tools and apps from [Evan Ray](https://github.com/jimbottle): data and analytics engineering by day, and the Raylytics products in between.

- [Lou](https://github.com/jimbottle/louisville-open-data-expenditure-bot): an agentic analytics assistant over Louisville Metro open data. [Try it](https://louisville.raylytics.io).
- [would-you-kindly](https://github.com/jimbottle/would-you-kindly): a Go terminal UI over the beads issue tracker, built for agent-to-human handoffs. Installs with Homebrew.
- [Just My Weather](https://github.com/jimbottle/just-my-weather): a Kotlin Android weather app that shows only what you choose. [On Google Play](https://play.google.com/store/apps/details?id=io.raylytics.justmyweather).

Every repository here follows the same [contributing guide](https://github.com/jimbottle/.github/blob/main/CONTRIBUTING.md) and [security policy](https://github.com/jimbottle/.github/blob/main/SECURITY.md). Site: [raylytics.io](https://raylytics.io).
