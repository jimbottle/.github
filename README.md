# .github

Default community health files for every repository under this account that does not carry its own copy (GitHub serves them automatically): `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md` (Contributor Covenant 2.1), the issue templates, and the pull request template. `profile/README.md` is the organization profile, which takes effect when this repo moves to the Raylytics org.

Source: the Raylytics Version Control Standard, section 11 (`STANDARD.md` in the `raylytics` repo).
